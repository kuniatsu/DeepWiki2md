# Devin DeepWiki One-Tap Exporter (for NotebookLM) 🚀

Devin AI上の社内Wiki（DeepWiki）を、ワンタップで一括Markdown化し、Google NotebookLMへのデータ連携を最適化するためのChrome拡張機能です。

## 📝 開発の背景
現在、プロジェクトごとに作成される **DevinのDeepWiki** は、社内の貴重なナレッジベースとなっています。しかし、以下の課題により、AI（NotebookLMなど）を活用した高度な分析や検索が困難でした。

1. **認証の壁:** DeepWikiはログイン必須のクローズドなSPA（Single Page Application）であり、外部のスクレイピングツールや単純なiPaaS連携ではデータを抽出できない。
2. **ページ数の変動:** プロジェクトごとに数十ページに及ぶことがあり、1ページずつ手動で保存・コピーするのは極めて非効率。
3. **データ形式:** NotebookLMで高い解析精度を出すには、プレーンテキストよりも構造化された **Markdown形式** が望ましい。

本ツールは、ブラウザ拡張機能として「ユーザーの既存セッション」を利用することで、これらの課題をスマートに解決します。

---

## ✨ 主な機能

- **ワンタップ・フルスキャン:** ルート画面（トップページ）の左サイドバーにある全リンクを自動検出。
- **認証バイパス取得:** ログイン済みのブラウザから内部通信（fetch）を行うため、追加の認証設定なしでクローズドな情報を取得可能。
- **自動Markdown変換:** HTMLから不要なタグ（UI要素など）を除去し、純粋な本文のみを抽出・整形。
- **NotebookLM最適化出力:** 取得した全ページを適切な区切り線（`---`）とともに1つのMarkdownファイルに結合し、一括ダウンロード。
- **ユーザーフレンドリーUI:** 非エンジニアでも迷わないよう、特定のページを開いたときのみ専用ボタンを画面上に表示。

## 🛠 インストール方法（開発者モード）

社内配布を想定し、フォルダ形式での導入手順を記載します。

1. 本リポジトリを `Clone` または `ZIPダウンロードして解凍` します。
2. Google Chromeのアドレスバーに `chrome://extensions/` を入力して開きます。
3. 右上の **「デベロッパー モード」** をONにします。
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 解凍した本ツールのフォルダを選択して読み込みます。

## 🚀 使い方

1. **DeepWikiへアクセス:**
   対象となるプロジェクトのDeepWikiルート画面（サイドバーに全ページが並んでいる状態）を開きます。
2. **エクスポート開始:**
   画面右下に表示される **「🚀 一括Markdown生成」** ボタンをクリックします。
3. **ダウンロード:**
   進捗が表示され、完了すると自動的に `DeepWiki_Export_[timestamp].md` が保存されます。
4. **NotebookLMへ投入:**
   [NotebookLM](https://notebooklm.google.com/) を開き、ダウンロードしたファイルをソースとしてアップロードしてください。

## ⚙️ 技術仕様

### 対象環境
- **Target URL:** `https://app.devin.ai/org/*/wiki/*`
- **Platform:** Google Chrome (Chromium-based browsers)

### 使用技術
- **Manifest V3:** 最新のChrome拡張仕様に準拠。
- **Content Scripts:** ページ内のDOM構造を直接解析。
- **Turndown.js:** HTMLからクリーンなMarkdownへの変換ライブラリ。
- **Async/Await Fetch:** 各ページの非同期一括取得による高速化。

### セレクター構成 (2026年時点)
- **Sidebar Selector:** `#app > div > main > ... > ul` (リンク一覧の走査用)
- **Content Selector:** `#app > div > main > ... > div` (本文抽出用)

---

## 🛡 セキュリティ・ポリシー
- **データプライバシー:** 本ツールはローカル（ユーザーのブラウザ内）でのみ動作します。取得したWikiデータを外部のサーバーに送信することはありません。
- **セッション利用:** ユーザーが現在ログインしているセッションを利用して読み取りを行います。パスワードなどをツール内に保存することはありません。
